# 네트워크 IP 기초 정리

IP 주소의 개념, 할당 방식(DHCP / Static), 분류, 통신 방식을 정리한 문서입니다.

---

## 1. IP (Internet Protocol) 개념

컴퓨터는 부팅 시 네트워크 설정을 읽어 **IP 주소를 세팅**한다.
이때 IP를 얻는 방식은 크게 **DHCP(자동)** 와 **Static IP(수동)** 두 가지다.

---

## 2. IP 주소 할당 방식

### DHCP (Dynamic Host Configuration Protocol) — 자동 설정

네트워크에 연결되면 **DHCP 서버가 IP를 자동으로 할당**해주는 방식이다.

- 클라이언트가 부팅/접속 시 DHCP 서버에 IP를 요청 → 서버가 사용 가능한 IP를 빌려줌(임대)
- IP뿐 아니라 **서브넷 마스크, 게이트웨이, DNS 주소**까지 한 번에 받아옴
- **임대(Lease) 개념**: 할당된 IP는 영구적이지 않고 일정 시간 후 만료되며, 갱신하거나 다른 IP로 바뀔 수 있음
- **장점**: 설정이 간편하고 여러 기기를 자동 관리 → IP 충돌 방지, 관리 편의성
- **단점**: 접속할 때마다 IP가 바뀔 수 있어, 고정 주소가 필요한 서버 용도에는 부적합
- **주 사용처**: 일반 PC, 노트북, 스마트폰 등 클라이언트 기기 / 가정용 공유기

> 참고 흐름(DORA): **D**iscover → **O**ffer → **R**equest → **A**cknowledge 순서로 IP를 임대받는다.

### Static IP — 사용자가 직접 설정

관리자가 기기에 **IP를 수동으로 고정 지정**하는 방식이다.

- IP, 서브넷 마스크, 게이트웨이, DNS를 사람이 직접 입력
- 재부팅하거나 시간이 지나도 **항상 같은 IP를 유지**
- **장점**: 주소가 변하지 않아 외부에서 안정적으로 접근 가능 → 서버, 네트워크 장비에 필수
- **단점**: 일일이 수동 설정해야 하고, 관리 실수 시 **IP 충돌** 위험. 기기가 많아지면 관리 부담 큼
- **주 사용처**: 웹/DB 서버, 프린터, NAS, 라우터·스위치 등 항상 같은 주소로 찾아야 하는 장비

> **한 줄 요약**: DHCP는 "빌려 쓰는 자동 IP"(편하지만 바뀔 수 있음), Static IP는 "직접 고정한 IP"(안정적이지만 수동 관리).

## 3. IP 분류

### 프로토콜(버전)에 따른 분류

| 버전 | 비트 수 | 표현 | 예시 |
|------|---------|------|------|
| IPv4 | 32bit (8bit × 4) | 10진수, `.` 구분 | `192.168.0.1` |
| IPv6 | 128bit (16bit × 8) | 16진수, `:` 구분 | `2001:0db8:85a3::8a2e:0370:7334` |

> 참고: 이미지의 `8bit*4`, `16bit*8`은 **바이트 단위** 표기입니다.
> 비트로 환산하면 IPv4 = 8×4 = **32bit**, IPv6 = 16×8 = **128bit**.

### 범위 기반에 따른 분류

- **Private IP (사설)**: 외부에서 직접 접근 불가, 내부망(LAN)에서만 사용
- **Public IP (공인)**: 인터넷상에서 유일하게 식별되는 주소

#### Private IP (사설 IP) 대역

| 클래스 | 범위 |
|--------|------|
| A | `10.0.0.0` ~ `10.255.255.255` |
| B | `172.16.0.0` ~ `172.31.255.255` |
| C | `192.168.0.0` ~ `192.168.255.255` |

## 4. 통신 방식 (전송 방식)

- **유니캐스트 (Unicast, 1:1)**: 특정 하나의 대상에게 전송
- **멀티캐스트 (Multicast, 1:N)**: 특정 다수(그룹)에게 전송
- **브로드캐스트 (Broadcast, 1:N)**: 불특정 다수(네트워크 전체)에게 전송
